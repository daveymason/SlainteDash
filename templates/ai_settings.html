Clinical AI Architecture: Deterministic Grounding & Model Execution Zero-Hallucination Guardrails
1. Live Deterministic Synthesis (Always Active)

Clinical actions (SBAR handovers, SOAP notes, NEWS2 acuity, drug-allergy contraindication screening) are never hardcoded or faked. The system reads live FHIR R4 resources directly from the store (Patient, Observations, Conditions, Allergies, Meds) and evaluates them deterministically using FastMCP tool rules. Even when external cloud models are unconfigured, clinical output is dynamically assembled from the patient's verified real-time records.

2. Neural Generation & Sovereign LLM Routing

When an LLM provider is active (local sovereign Ollama models on port 11434 or cloud models via OPENAI_API_KEY), the live de-identified FHIR context is passed to the model prompt to synthesize fluid clinical prose while maintaining strict resource citations ([Observation/...], [Condition/...]).
